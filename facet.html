Facet

General-Purpose Multi-Dimensional Signal Processing Software Suite

OrganizationSystems Engineering and Development Corporation (SEDC)
Work period1985–1990
ContributorJohn Schveibinz

Product overview

Facet was an internally funded research and development effort to create a general-purpose multidimensional signal processing suite in Fortran. The suite was intended to be marketed as a modular, pipeline-oriented environment featuring a comprehensive library of multidimensional algorithms, with future optimization for math coprocessors planned.

Standardized data exchange formats supported seamless data flow between processing stages and interoperability with FORTRAN or C libraries. The visual environment provided high-quality, interactive 3D rendering. Through a standard graphical user interface, users could manipulate cutting planes through 3D data cubes to extract and evaluate precise orthogonal cross-sections.

Work performed

Led the Facet development project, including the conceptualization and software engineering of the signal processing toolkit.

Project leadership; software engineering

Engineering significance

Combined a modular processing pipeline, standardized data exchange, and interactive visualization in a reusable environment for signal processing research and design. The ability to inspect orthogonal cross-sections through 3D data cubes helped users examine multidimensional results in detail, while library interoperability supported integration with existing FORTRAN and C algorithms.
