Third-Party MATLAB Hyperspectral Toolkit

Hyperspectral Material Detection and Classification Interfaces

OrganizationApplied Signal and Image Technology (ASIT)
Work period1996–2009
ContributorJohn Schveibinz

Product overview

A third-party hyperspectral toolkit effort associated with ASIT’s U.S. Navy SPAWAR SBIR Phase II research on material detection and classification.

Work performed

As a Phase II lead engineer, wrote MATLAB and Visual Basic interface software for core algorithms developed by Joseph C. Harsanyi. Helped design and compose a third-party MATLAB hyperspectral toolkit for presentation in Boston.

Interface development; toolkit design; Joseph C. Harsanyi (core algorithms)

Engineering significance

Made specialized detection algorithms accessible through software interfaces and an application-focused toolkit design. The source establishes development and presentation work; a commercial release date is not documented.
