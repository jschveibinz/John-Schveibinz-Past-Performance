Prospectre

Real-Time Hyperspectral Image Processing System

OrganizationApplied Signal and Image Technology (ASIT)
Work period1996–2009
ContributorJohn Schveibinz

Product overview

A real-time hyperspectral image processing system designed for applications including mineral exploration and mining.

Work performed

Designed the system and participated in its implementation, translating hyperspectral processing requirements into a processing architecture suitable for mining applications.

System design; collaborative implementation

Engineering significance

Connected hyperspectral analysis methods with an application-oriented processing system. A Navy SBIR success publication independently identifies Prospectre as an outcome of ASIT’s Phase II spectral processing program.
