# John Schveibinz — Past Performance

A dependency-free GitHub Pages site with ten individually addressable historical product descriptions and an SBIR context page.

## Publish

1. Create the public repository `jschveibinz/John-Schveibinz-Past-Performance`.
2. Upload the contents of this directory to its root on the `main` branch, including `style.css` and `.nojekyll`.
3. In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. Wait for the Pages deployment to succeed. Open the site and each product URL before citing them.

Expected site URL: https://jschveibinz.github.io/John-Schveibinz-Past-Performance/

`product-citations.csv` contains the ten expected URLs and suggested citations. They are not live until deployment succeeds. If the owner or repository changes, update canonical links and citation URLs in all HTML files and the CSV.

## Stable links

Retain repository name, account name, and HTML filenames after citing. Edit content in place. If a page must move, keep a redirect at its old path. GitHub Pages links depend on the account and repository remaining available; they are not archival identifiers. Consider a versioned archival deposit with a DOI for stronger permanence.

## Editorial conventions

Work periods are employment intervals, not verified release dates. Exact release years are unknown, so citations use n.d. Historical products are described; original artifacts are not distributed. Contributor language distinguishes team products from personal work. No software or hardware license is implied.
